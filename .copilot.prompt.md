When I execute `syncript sync --push-only`, I expect to force all changes to be pushed to the remote server without pulling any changes from the remote server. This means that if there are any conflicts (i.e., files that have been modified both locally and remotely), the local changes will take precedence and will be pushed to the remote server, overwriting any conflicting changes on the remote server.
